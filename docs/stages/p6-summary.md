# P6 阶段总结：受控桌面任务接入个人任务服务

2026-10-04，分支 `p6-desktop-task-service`。结论：按[p6-design](p6-design.md)限定的单人、已有安装、测试VM TextEdit任务范围，工程验收通过。不是通用桌面代理、无人值守解锁、C3发布或第二人复现；P5真实168小时与P7实际用途不因此完成。

## 交付与边界

专业上是类型化任务队列、持久执行权、VM最终派发门禁和独立证据验收。直白说：提交1–10行交接文字，官方Harness在测试VM的TextEdit中输入并保存，后端核对后才允许下载。仍使用官方App与唯一模型循环，Flash/off；每任务最多30次实际调用，观察、失败及工具内部请求也计数。

正式入口见[backend README](../../backend/README.md)：独立服务初始化/启动、`desktop-submit`、查询/停止、`desktop_operator worker-once`及产物下载。提交不自动授予执行；操作者必须先完成明确批准的切换、额度和环境检查。共享桌面锁沿用原安装；P5旧队列与新桌面队列分离。已开始的桌面任务不支持自动resume，未知副作用不重放。没有新增产品UI、自动部署或干净机器安装器。

当前需要操作者保持官方App/VM就绪、串行切换并提供私有授权配置；不自动解锁、改SSH/网络/睡眠或清除隔离。新版可受控执行，不等于用户已经独立采用。默认分支/原P5运行环境不做升级，阶段成果先保留在P6分支。
