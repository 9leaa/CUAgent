# P7 截图坐标点击路径（2026-10-17）

用户明确要求采用已有截图能力，不再持续修补Calc控件AX兼容性。本方案替代先完成AXSheet/父链矩阵才研究生产路径的顺序；旧失败及原证据保留。范围先是截图坐标foreground点击的强制AX点命中，不宣称整个观察、选中验证、键盘焦点已无AX依赖。

## 实现

在现有Driver 0.34.1隔离源码添加独立visual_point模块，foreground像素路径直接采用该模块，不先尝试AX点查询、不循环回退。模型给出的仍为当前窗口截图像素；沿用截图尺寸/缩放转换和原snapshot绑定。保留转换时的窗口几何，激活后投递前再次核对同PID/window、可见状态、几何完全一致及至少4逻辑像素内缩范围（保守拒绝边框，不推断内容语义）。随后无过滤WindowServer点查询必须直接命中同PID/window；缺符号、返回错误、遮挡或几何变化均拒绝，不跳过窗口寻找下层目标。

窗口查询不读控件树，不依赖AXWindow/AXParent成功。它是窗口级误点防护，不代替模型视觉理解；无界面语义成功声明。原AX元素点击路径不变。窗口级激活仍使用原逻辑，若此处后续成为阻塞，再独立分析，不能将本改动宣传为完全无AX。

仍有查询到投递的竞态：保留原VM隔离、任务授权、停止/预算/UNKNOWN语义、一次派发及操作后新截图。新模块中两秒截止只拒绝超时后的动作，不声称能中断阻塞FFI；外部任务超时照旧，不自动重试。

## 验证

纯策略反例覆盖跨PID、同PID不同窗口（菜单/Sheet不需解析角色）、缺符号/查询错误、移窗/缩放、非有限坐标、边框/窗口外及超时，均零派发；正确样本一次派发、动作失败不重试。必须测试生产调用连接确实走新路径且不调用AX点命中。固定Rust1.97.1/SDK15.5完整构建，新增独立包及身份核验，不能替换原Driver或沿用旧摘要。

真实VM仍需新鲜截图、当前候选权限和服务准入，再跑全新DSH Flash/off输入→保存→重开→独立读回，30raw/180秒；不能拿人工操作或单元测试代替。先交付该可核验路径，再扩展跨软件验证，停止追加Calc专用AX父链修补。

## 实测后的准入时序修正（2026-10-17）

019 在应用配置切换后因桌面复核超过30秒拒绝，模型未派发、raw=0。测试监督流程须在应用就绪后另采新截图，再派发；不延长30秒限制。020 在权限助手检查通过后，因宿主与VM时钟偏差导致跨机时间比较拒绝。修正设计：监督器在同一次远端调用内，于启动助手前、助手退出后分别采集VM时间，要求上游 verified_at 落在此区间（仅秒精度向下舍入）；宿主仍独立验证 startedAt/checkedAt/now 的300秒期限。VM区间不得逆序或超过宿主整轮时长；不通过增加跨机宽限掩盖旧证据。保持PID、SHA、run/session、权限和实际截图检查，旧证据不补写。
