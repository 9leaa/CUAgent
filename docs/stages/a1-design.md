## 目标与边界

专业目标：框架无关工具核心、官方 Harness 适配、持久任务策略与独立验收组成可扩展通用插件路径。直白说：能认真处理三份文件和一张表，还能安全地增加工具、重启和续接，而不是只聊天或口头说完成。

复用官方 Desktop `0.2.0-rc.2` / 内置 Node `24.18.1` / 同版源码参考 `639ed015`，实际版本再核对；模型沿用已配置账号路线，不读取或复制凭证。只使用新建的 CUAgent 专用测试目录，禁止宿主 GUI、shell、任意网络、MCP、子 Agent 和动态插件安装。VM、Driver、SSH/VNC 与 C0/C1/C2 源码基线保留，不停 VM 或改端口。

## 实现拆分

补充实施前约定：启动预检与运行时复用同一个私有任务配置校验器，统一拒绝重复 session/run、重叠工作区、重复账本、跨任务审计进入模型根和不安全配置路径；预检不得创建账本或重置预算。缺失或非法配置的真实注册表测试必须证明所有任务拒绝、无工具副作用。

文件安全补充：在新的临时 fixture 中通过同版官方注册表实测完整 A1 路径/类型/大小/覆盖/链接/保护审计拒绝，核对稳定错误码、原文件不变和失败派发仍计预算；不重复使用旧 A0 边界任务，也不将无模型注册测试冒充 VM 回归。

补充实施前约定（2026-10-02）：官方仅允许首轮开始前选择 preset，因此新建授权只读会话验证 `a1-controlled` → `a1-readonly`，再验证开始后切换被锁定；旧业务会话与预算保留。只读 preset 只注册 calculate/list/read/CSV，根审批也固定相同子集，不能用 preset 放宽审批。新增 `workspace_text_fingerprint` 为人工审查的插件示例候选，不加入默认六工具或自动任务审批；仅在专用示例任务显式允许、挂载插件后运行，其集成测试不计为第二人验收。

1. 建立新的 A1 profile 补丁/preset、构建/配置与启动入口，A0 五工具白名单不变。A1 显式审查的工具集合为原五工具加 `workspace_csv_stats`；扩展示例需要单独明确登记，不能由模型注册。复用文件核心和官方图片附件链路，不增加模型主循环或自制 UI。
2. CSV 适配只把固定任务根和规范化相对路径传给已有统计核心；保留 1 MiB/10000 行/100 列/20 数值列限制、非 UTF-8/类型/链接/越界拒绝，取消前后检查，不运行 shell。
3. 完善 A1 独立持久准入/审计：run/session/call 关联、30 次真实工具派发、耗时、脱敏参数摘要/产物引用。根 guard 和模型请求清单均检查能力；配置身份/能力变化必须拒绝复用旧账本，重载、重启、会话切换与压缩不能重置预算。失效配置和审计不可写 fail-closed。
4. 工具卸载/重载使用固定版 Cordis 生命周期；不允许执行模型管理插件。官方会话/preset/压缩操作由开发侧受控检查发起，独立核对实际工具、取消和跨会话边界，不只测试静态 YAML。
5. 新三份无个人数据文本 fixture 与来源期望：模型读取三份、提取字段、生成 Markdown/结构化结果、读回；开发侧独立核对完整字段、来源引用、输入与输出字节哈希。期望与验证程序不放入模型工作区，不使用模型自评。
6. `sales.csv` 使用原公开 fixture，但在新 A1 run 中重新执行；模型真实调用统计工具，生成 JSON/Markdown 并读回。独立验证行列、missing/count/sum/min/max/mean、输入 SHA 和全部报告字段，不以包含几个数字的宽松检查冒充通过。
7. 提供通用受控插件示例、参数/结果 schema、稳定错误码、取消/图片说明及等效流程；说明文档/Skill 不授予权限。第二位开发者需不修改主循环独立接入新受控工具并提交实际正常/拒绝证据，不能把本代理的测试算第二人验收。
