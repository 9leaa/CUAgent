# P7 运行状态与终态证据分离

2026-10-07，先方案后代码。当前inspectDesktopSession即使官方session/list声明running=true，也读取正在追加的zstd文件；遇到未完整写入的帧或读取期间长度变化即抛异常，Worker因此撤销原执行权。官方持久化实现使用可追加的拼接帧，而非每次原子替换完整文件。先以真实zstd部分尾帧及运行中RPC模拟复现，不把该风险推断为第三例确定根因。

官方清单必须严格匹配原session/cwd、唯一身份且running为布尔值。running=true时只返回明确的非终态与evidencePending=true，不读取/归档正在写的日志，日志相关计数用null而非猜零；不声称原prompt已被证实。Python客户端仅允许这一个严格非终态形状，guest实际预算/在途数仍独立查询，既有心跳、300秒期限及失权停止不变。

running=false时仍按原规则完整读取、解压、分类、核对原prompt及终态后独占归档；坏文件、未知状态、错误cwd、重复身份、变化的终态证据一律拒绝。不截断、修复或忽略损坏日志，不重试模型或副作用，不修改官方源码/活动profile/P5冻结代码。运行中取消继续调用既有原session取消入口，不要求先读完整日志。

回归覆盖部分zstd尾帧下live查询不误停、终态同坏帧拒绝且无归档、live→完整terminal后精确归档、错身份/非布尔/重复拒绝、Python不允许pending伪装成功。原第三例interrupted-tool-result为官方合成恢复记录，其时间复用最后真实事件，不能拿它确定中断发生时刻或根因。原失败不重跑；新版真实验证另列全部尝试。
