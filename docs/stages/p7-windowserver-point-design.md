# P7：无AX父节点时的屏幕点窗口归属研究

2026-10-15；沿用未完成的p7-expense-reconcile。本方案先于实现；018原任务已停止，不恢复、不替换其失败成绩。目标仍是实际DSH驱动Calc输入、保存、重开与独立读回，不把诊断代替业务验收。

## 已知证据与未证实项

018系统级AX命中返回Calc PID468，但首节点AXWindow及AXParent均NoValue；因此父链解析无法获得window123。只能确认这次AX关联信息不足，不能确定模型定位错误，也不能断言整个LibreOffice均不支持窗口归属。当前没有证据证明更换点击点能稳定解决问题。

研究参考固定为[yabai dd845723416f5fe92af49fad5ebab00369e07edd的声明](https://github.com/asmvik/yabai/blob/dd845723416f5fe92af49fad5ebab00369e07edd/src/misc/extern.h)及[窗口点查询实现](https://github.com/asmvik/yabai/blob/dd845723416f5fe92af49fad5ebab00369e07edd/src/window_manager.c#L869)。其中SLSFindWindowAndOwner与SLSConnectionGetPID提供另一条窗口编号/所有者取证路径。这是第三方项目使用的macOS私有SPI，不是Apple稳定API契约，也不证明本VM可用。仅参考接口和行为，不复制其跳过本进程或边框窗口的逻辑，不安装yabai或其脚本注入组件。

## 实施顺序

1. 先做独立只读候选，不进入正式点击路径。动态解析固定SkyLight符号；缺符号、非零错误、无连接/窗口/PID、非法坐标一律返回不可用。固定无过滤查询，绝不跳过首个命中窗口继续找目标。保存原返回码和身份，不保存窗口正文或名称。
2. 为FFI使用repr(C)的双f64 CGPoint、明确整数宽度和空指针约束，核对当前SDK/架构；单独验证符号存在不算调用成功。私有接口调用置于可超时退出的独立诊断进程，超时保留UNKNOWN且不重试；不要声称普通计时器可以中断阻塞FFI。
3. 在测试VM采集同周期完整桌面、系统级AX命中PID、WindowServer命中窗口/PID及独立窗口清单。覆盖无遮挡目标、另一个应用遮挡、同应用第二窗口、Sheet、菜单/系统弹窗、桌面空白和边缘点。每个场景有当前实际界面证据；不拿018旧坐标当当前授权点，不靠预期值生成查询结果。
4. 只有上述结果支持精确命中且失败可拒绝，才另补生产接线设计。可能的接线要求是系统级AX PID、WindowServer PID/window及已绑定目标同时一致；AX若明确解析出不同窗口，必须拒绝。AX类型错误、跨PID、超时不能归入“缺父节点”而被替代路径掩盖。不得仅用PID相同、矩形包含或窗口列表顺序放行。
5. 生产接线必须保持当前激活/置顶检查、投递前检查、一次投递、投递后新观察、原调用预算、停止及UNKNOWN语义。WindowServer查询和投递仍有竞态，不宣称完全消除。若私有接口在目标平台不可靠，保留拒绝并比较其它可验证传输路径，而不是扩大桌面权限或禁用保护。

- 纯适配测试覆盖符号缺失、返回错误、零/负身份、非有限坐标、同PID不同窗口、跨PID、查询矛盾及超时，全部断言零动作；反向移除身份比较后必须有测试失败。
