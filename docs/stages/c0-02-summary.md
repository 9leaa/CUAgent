# C0-02 阶段总结

日期：2026-10-01；分支 `c0-02-fixed-ui`。方案先于实现，见 [技术方案](c0-02-design.md)。结论：原计划九组计算器与三个基础 GUI 用例均至少真实独立成功一次；不是 C1/C2 验收。未提交、推送或发布。

## 做了什么、怎么做

将单例桥接扩为不可由模型改写的任务注册表，新增加减、受控字段输入和新截图内滚动；模型仍由官方 Harness 循环驱动。原生 AppKit fixture 只提供真实表单/滚动/文本编辑界面，保存使用系统 NSSavePanel。模型没有 shell、任意路径、任意应用或验证器工具。

保存面板有独立 CGWindowID，但 Driver 的正文 AX 树包含 sheet。背景 AX、背景像素及正文前台输入多轮未生效。最终仅对新观察中选择的 Save，核对同 PID/应用的唯一可见 sheet 及按钮几何，固定 return/foreground 绑定到 sheet 自身，finally 恢复正文目标。确认键返回仅记 attempted_action；新正文观察证实 Saved 状态及实际文件后才记一次 Save 完成。没有自动重放，第二次确认仍由模型根据新观察决定。

执行端保留显式授权、PID/窗口检查、快照有效期、单任务互斥、持久 30 次预算、停止和审计。Driver `effect: refused` 与 `code: delivery_failed` 等失败不再当成完成。副作用不确定阻止新动作；独立 verifier token 不进入模型工具配置。

## 怎么验证

固定官方 Desktop 0.2.0-rc.2、内置 Node 24.18.1、`deepseek-account/deepseek-flash`、Driver 0.28.2、guest Python 3.12.14、同一隔离 macOS 开发 VM、每任务 30 次实际请求（包括内部及失败请求）。原始证据在 VM `C0Evidence/<run-id>`；host 私有报告 `.runtime/runs/`，不公开凭证或原始桌面记录。

| 用例 | 独立结果 | raw 请求 |
|---|---|---|
| 27+16、8+9、125+75 | 43、17、200；全部通过 | 20、16、22 |
| 90−17、50−28、101−1 | 73、22、100；全部通过 | 20、20、20 |
| 12×34、7×8、15×6 | 408、56、90；全部通过 | 20、16、18 |
| 表单 `form_…001` | 预定字段、真实提交状态与提交文件一致 | 12 |
| 滚动 `scroll_…002` | 真实滚动，初始离屏目标进入可见区域，marker 与产物一致 | 14 |
| 文档 `document_…008` | 新 Saved 状态、实际 task-note.txt、result.txt/读回与独立正文一致 | 16 |

上述 run 均以 `c0_02_` 开头、日期 `20261001`；计算器均为 `_001`。汇总 `c0-02-calculator-report.json`（9/9）及 `c0-02-gui-report.json`（3/3）。独立验证核对真实 raw dispatch/result 完整、固定轨迹、新界面、实际产物读回及程序预定期望；官方 turn/end 并非成功依据。验证后关闭准入并结束对应 bridge，VM 保持运行。

保留失败：滚动 `_001` 因 AXScrollArea 不可用未执行真实滚动；文档 `_001`～`_006` 没有产物，分别为窗口误绑定、背景/前台输入未生效、键盘前台目标失败；`_007` 已有正确文件，但完成轨迹重复记账，独立 gate 为 UNVERIFIED，没有倒改旧报告。共 12 个成功任务、8 个未通过尝试；开发诊断/安全门槛不混入任务成功数。所有真实尝试都保留，不能只展示最终通过率。逐轮修复由开发者介入；未声称这些初次开发任务为零介入稳定评测。

无模型回归：`python3 -m unittest discover -s tools/mac_vm/tests -q` 35/35；`node --test agent/tests/*.test.mjs` 36/36；官方 App Node/工具库的 C0 适配测试 1/1；`git diff --check` 通过。安全接口 gate 的错误 token、模型调用 verifier、shell、停后派发均拒绝；mock 另覆盖 30 次预算、持久账本、过期/越界/拒绝、UNKNOWN 与假成功。不能用 mock 推断 C2 故障/恢复已完成。

## 限制和下一步

这是同机开发 VM，不是干净无凭证发布基线或通用 benchmark。窗口尺寸/标题与字段为固定测试任务；没有证明任意网页、跨应用或长流程可靠。继续按原计划 C1 六类前后各三次，再做 C2 六例×三次至少 17 次独立成功、故障集与安全回归；本阶段通过不替代后续门槛。
